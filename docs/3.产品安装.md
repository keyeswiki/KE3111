## 步骤6: 舵机角度校准

⚠ <span style="color: rgb(0, 209, 0);">**特别提醒：舵机已经安装到亚克力板上，就不需要再把舵机拆下来，直接将舵机的线材连接到舵机控制模块上对应的引脚上即可。同时，18650电池盒也不需要从亚克力板上拆下来。**</span>

⚠ <span style="color: rgb(255, 76, 65);">**注意：此步骤需要进行舵机角度的校准，将舵机的初始角度设置为90°，按图示操作**。</span>

**校准舵机所需零件：**

![D1](./media/D1.png)

**舵机接线：**

| 舵机 | 舵机控制模块 |
| :--: | :----------: |
| 棕线 |      G       |
| 红线 |      V       |
| 橙线 |      S       |

| 舵机控制模块 | ESP32舵机驱动板 |
| :----------: | :---------: |
|      5V      |     5V      |
|      G       |     G       |

![D2](./media/D2.png)

**手指按下这个舵机控制模块上的90°按钮，舵机就可以转到90°位置。**

![D3](./media/D3.png)

⚠ <span style="color: rgb(200, 70, 100);">**提醒：按照上面图示完成舵机角度的校准后，请将所接线拆除，无需保留。**</span>
